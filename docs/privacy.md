# Matchday privacy notice

The privacy notice is [`public/privacy.html`](../public/privacy.html). It ships
with the app, so it opens with no signal, at `./privacy.html` beside the app
(linked from the sign-in screens and from Setup).

It was written from the code - every service the app's data touches is named
in its section 9 - so keep it in step: anything that sends data somewhere new,
keeps something new, or keeps it for longer changes that page in the same
commit.

> **Not legal advice.** Matchday handles children's information. Before real
> families and academies use it, have the notice read by someone who knows UK
> data protection law (UK GDPR, the Data Protection Act 2018 and the ICO's
> Children's code), and fill in the highlighted parts: the contact email, the
> database region, which service sends sign-in emails, which Gemini tier the
> shared key is on, the backup period, and the date.
